# AEGIS benchmark

Generated by `python scripts/benchmark.py` over the 7 red-team scenarios (44 agent actions, each labelled harmful or legitimate).

| Metric | Result |
|---|---|
| Decisions matching the expected outcome | 44/44 |
| Harmful actions prevented (masked, held or blocked) | 12/13 |
| Harmful actions detected (incl. flag-and-alert) | 13/13 |
| Legitimate actions that ran automatically | 30/31 |
| Legitimate actions sent to a human by policy (high-value refund) | 1 |
| Legitimate actions wrongly held or blocked | 0 |
| Decision latency p50 / p95 / p99 | 0.268 / 2.126 / 18.376 ms (2,640 decisions) |
| Throughput (one CPU core, full pipeline) | ~1,107 decisions/s |
